==============================================
 Speed Dial Sync(PC用スピードダイヤル)使い方
==============================================

Chromeの「新しいタブ」を、よく使うサイトをワンクリックで開ける
スピードダイヤル画面に置き換える拡張機能です。


■ 1. インストール方法
----------------------------------------------
1) このZIPを展開します。
   ※ 展開してできた「speed_dial_sync」フォルダは、
     インストール後も使い続けます。削除したり、別の場所へ移動したり
     しないでください(「5. 注意」を参照)。
     おすすめは、ドキュメントなど、消さない場所に置くことです。

2) Chromeのアドレスバーに  chrome://extensions  と入力して開きます。

3) 右上の「デベロッパー モード」をオンにします。

4) 左上に出る「パッケージ化されていない拡張機能を読み込む」を押し、
   展開した「speed_dial_sync」フォルダを選びます。

5) 新しいタブを開くと、「はじめに」画面が出ます。
   ・以前のバックアップファイルがある → 「JSONファイルを読み込む」
   ・何もない → 「読み込まずに空で始める」
   ※ どちらかを選ぶと、この画面は二度と出ません。
     あとでバックアップを読み込みたいときは、右下「⋮」メニューの
     「バックアップをインポート」を使います。

【補足】Chromeを開くたびに「デベロッパー モードの拡張機能を無効に
しますか?」という通知が出ることがあります。そのときは「キャンセル」
を押せば、そのまま使い続けられます。


■ 2. 基本の使い方
----------------------------------------------
◆ リンクを追加する
  カード一覧の最後にある「+」を押し、タイトルとURLを入力して保存します。
  アイコンは次から選べます。
    ・自動(サイトのファビコン)
    ・URLで指定
    ・端末から選択(手持ちの画像)
    ・プリセットから選択(Gmail、YouTubeなどの定番アイコン、A〜Z、0〜9 など)

◆ リンクを開く
  カードをクリックすると、今のタブでそのまま開きます。

◆ リンクを編集・削除する
  カードにマウスを乗せると右上に「✎」が出ます。押すと編集できます。
  編集画面の「削除」で消せます。

◆ グループ(タブ)
  画面上部のタブがグループです。
  ・「+ グループ」 … 新しいグループを作る
  ・タブをダブルクリック … 名前の変更 / 削除
  ・タブをドラッグ … 並べ替え

◆ ドラッグ&ドロップ
  ・カードをカードの上へドラッグ … 並べ替え
  ・カードをグループのタブへドラッグ … そのグループへ移動

◆ ページ送り
  カードが1画面に収まらないときは、自動で複数ページになります。
  ・画面の左右端の「‹」「›」ボタン
  ・マウスホイール(上へ回す=前、下へ回す=次)
  グループの最後のページまで進むと、次のグループへ移ります。


■ 3. 「枠」機能(デスクトップのFences風)
----------------------------------------------
グループの画面の中に、好きな位置・大きさの「枠」を置いて、
カードを枠ごとに整理できます。

  ・作る … 右下「⋮」→「枠を追加」
  ・移動 … 枠の上部(ヘッダー)をドラッグ
  ・大きさ変更 … 枠の右下の角をドラッグ
  ・名前変更 … 枠にマウスを乗せて「✎」
  ・色の変更 … 枠にマウスを乗せて、ヘッダーの小さな色見本をクリック
  ・削除 … 枠にマウスを乗せて「✕」
          (中のカードは消えず、通常の一覧に戻ります)
  ・カードを枠に入れる … カードを枠へドラッグ
  ・カードを枠から出す … 枠の外の空いている場所へドラッグ


■ 4. 右下の「⋮」(縦三点)メニュー
----------------------------------------------
画面の右下にある丸いボタンです。押すと次のメニューが出ます。

  [ 枠を追加 ]
     現在のグループに、新しい枠を作ります。

  [ 表示設定 ]
     見た目を自分好みに変えます。変更は、保存を押すまで確定しません。
       ・テーマカラー
       ・プリセットアイコンの背景(白地 / 黒地 / 透過)
       ・列数、左右・上下の余白、アイコンの大きさ
       ・グループバー / カードの不透明度
       ・背景画像(URL指定、手持ちの画像、同梱のおすすめ画像から選択)
       ・リセット(初期設定に戻す)
     ※「ホーム画面アイコンの色」はスマホ用の項目なので、使いません。
     ※「Speed Dial 2バックアップのインポート」は、Speed Dial 2(別の拡張機能)
       のバックアップを取り込む機能です。今のデータは全部置き換わります。

  [ バックアップをエクスポート ]
     リンク・グループ・枠を、JSONファイルとして書き出します。
     ダウンロードフォルダに「speed-dial-backup-日付.json」ができます。

  [ バックアップをインポート ]
     書き出したJSONファイルを読み込みます。
     今のデータは全部置き換わります(確認が出ます)。


■ 5. 注意(大事です)
----------------------------------------------
◆ データはこのパソコンのChromeの中にだけ保存されます
  ・クラウド同期はありません。別のパソコンやスマホには引き継がれません。
  ・別のパソコンへ移すときは、「バックアップをエクスポート」で書き出し、
    移動先で「バックアップをインポート」してください。

◆ こんなときにデータが消えます
  ・拡張機能を削除したとき
  ・「speed_dial_sync」フォルダを移動・削除・名前変更したとき
    (Chromeが別の拡張機能と見なすため、中のデータが引き継がれません)
  → 大きく整理したあとや、フォルダを動かす前には、必ずエクスポートで
    バックアップを取っておいてください。

◆ 表示設定(色・背景など)はバックアップに含まれません
  別のパソコンでは、表示設定をもう一度やり直してください。


■ 6. 更新するとき
----------------------------------------------
新しいバージョンのZIPをもらったら、
  1) 今の「speed_dial_sync」フォルダの中身を、新しいものに上書きします
     (フォルダの場所は変えないでください)
  2) chrome://extensions を開き、この拡張機能の「再読み込み」(丸い矢印)を押します
データはそのまま残ります。念のため、先にエクスポートしておくと安心です。


■ 7. 困ったとき
----------------------------------------------
・新しいタブがいつものGoogle画面に戻った
   → chrome://extensions で、この拡張機能がオンになっているか確認してください。
・アイコンが表示されない
   → 「✎」から、アイコンを「プリセット」か「端末から選択」に変えてください。
・インポートがうまくいかない
   → このアプリでエクスポートしたファイルか、グループとリンクの入った
     JSONファイルを選んでください。
